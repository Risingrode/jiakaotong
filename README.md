# 驾考通 · 科一二三四一站通关

纯静态网站，零依赖、零图片，所有图形由 Canvas / SVG 代码绘制。手机、电脑均可使用，支持离线（PWA）。

## 运行
任意静态服务器即可：`python3 -m http.server 8000`，浏览器打开 http://localhost:8000

## 结构
| 文件 | 内容 |
|---|---|
| index.html / css/style.css / js/core.js | 外壳：路由、存储、语音、音效、首页、学车流程、设置 |
| js/quiz.js | 科一/科四 练习引擎：顺序/随机/章节/专项/错题/收藏/全真模拟考试 |
| js/qb1.js / js/qb4.js | 科目一题库（569题）/ 科目四题库（392题） |
| js/signs.js / js/ref.js | 200 个交通标志 + 40 个仪表指示灯；图鉴、交警手势动画、信号灯、记分规则、评判标准、罚款、汽车构造 |
| js/sim2.js | 科目二场地模拟（倒库/侧方/坡道/直角/曲线，手动/自动挡，后视镜，电子评判，教学演示） |
| js/sim3.js | 科目三路考模拟（压缩版，源码在 src/sim3/，`node src/sim3/build.js` 构建）+ 灯光模拟考试 |
| CONTRACT.md | 模块接口约定 |

题库与评判标准依据现行法规编写，仅供学习参考，以当地车管所规定为准。
